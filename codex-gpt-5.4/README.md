# Maze Runner

Клиентская веб-игра с процедурной генерацией лабиринтов на `TypeScript + Vite + Canvas`.

## Запуск

```bash
npm install
npm run dev
```

Дополнительно:

```bash
npm run build
npm run preview
npm run test
```

## Управление

- ПК: перетаскивание мышью внутри поля, `WASD`, стрелки.
- Мобайл: drag по игровой области.
- `Space` или кнопка паузы: пауза.
- Кнопка рестарта: перезапуск уровня.

## Отладка

- Откройте `/?debug=1`, чтобы включить debug overlay.

## Особенности

- Seed-детерминированная генерация идеальных лабиринтов.
- Прогресс уровня и лучшие времена сохраняются в `localStorage`.
- Статический буфер для стен и отдельный проход рендера для игрока/HUD.
