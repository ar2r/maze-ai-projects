# QA Test Plan - Maze Runner

## 1. Матрица окружений

- Desktop:
  - Chrome (latest)
  - Firefox (latest)
  - Safari (macOS latest)
  - Edge (latest)
- Mobile:
  - iOS Safari (16+)
  - Android Chrome (latest)

## 2. Smoke checks

- Игра запускается (`npm run dev`), отображается меню.
- `Start` запускает уровень 1.
- Лабиринт отображается, игрок двигается.
- Финиш достижим, показывается экран результатов.
- `Next`/`Retry` работают корректно.

## 3. Генерация лабиринта

- На каждом уровне лабиринт новый (при том же `baseSeed` и уровне - повторяемый).
- Нет недостижимого финиша.
- Уровни усложняются: рост `rows/cols`, уменьшение визуально доступного коридора.
- Границы лабиринта не имеют "дыр" наружу.

## 4. Управление и события ввода

- Desktop mouse drag: удержание и перемещение курсора двигает игрока.
- Desktop keyboard: `WASD` и стрелки работают.
- Mobile joystick: в режиме `Auto`/`Joystick` движение плавное.
- Mobile drag: в режиме `Drag` движение по тачу корректно.
- Быстрые свайпы: нет телепорта сквозь стены.
- `pointercancel` не ломает управление.
- Во время игры нет случайного скролла/zoom-прыжков страницы.

## 5. Коллизии

- Сквозь стену пройти нельзя.
- При диагональном упоре игрок скользит вдоль стены.
- Нет залипания в углах при коротких/длинных движениях.
- Счётчик `Hits` увеличивается при касаниях стен.
- На мобильных при коллизии есть виброотклик (если поддерживается и включен).

## 6. UI/UX

- На 360x640 кнопки остаются крупными и нажимаемыми.
- На desktop видны focus-style при `Tab` навигации.
- Start/Continue/Settings доступны и предсказуемы.
- Экран результатов показывает время, касания, best time.
- Settings применяются сразу и сохраняются после перезагрузки.

## 7. Сохранение/восстановление

- После перезагрузки сохраняются:
  - `currentLevel`
  - `baseSeed`
  - `bestTimes`
  - настройки (`controlMode`, `sound`, `vibration`, `debug`)
- `Continue` возвращает к сохраненному уровню.

## 8. Edge cases

- Смена ориентации во время игры: canvas корректно ресайзится.
- Изменение размера окна desktop: отрисовка не ломается.
- Переключение вкладки/потеря фокуса: игра ставится на паузу.
- Пауза/Resume/Restart не ломают таймер и коллизии.

## 9. Производительность

- Цель: близко к 60 FPS на среднем смартфоне.
- Нет заметных фризов при генерации уровня.
- Отрисовка стабильна: статический слой стен рендерится через offscreen буфер.
- В игровом цикле нет тяжелых аллокаций (проверять Performance panel).

## 10. Авто-проверки

- `npm run test:run` проходит:
  - `maze.test.ts`
  - `collision.test.ts`
- `npm run build` собирается без ошибок TypeScript.
